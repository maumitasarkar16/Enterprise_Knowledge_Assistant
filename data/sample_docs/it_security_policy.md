# Northstar Analytics — IT Security Policy (Sample)

## Data Classification
Company information is classified as Public, Internal, Confidential, or Restricted. Customer personally identifiable information and production credentials are Restricted.

## Multi-Factor Authentication
Multi-factor authentication is mandatory for corporate email, source-code hosting, VPN, cloud consoles, and administrator accounts.

## Security Incidents
Suspected phishing, credential exposure, malware, lost corporate devices, or unauthorized access must be reported to the Security Operations team within 30 minutes of discovery. Employees should preserve relevant evidence and should not attempt destructive remediation unless instructed.

## Production Access
Production access follows least privilege. Privileged production access must be approved by both the employee's engineering manager and the system owner. Access is reviewed quarterly.

## Local Development
Real production customer data must not be copied to developer laptops. Approved synthetic or anonymized data should be used for local testing.
